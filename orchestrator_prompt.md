# Orchestrator Context: Video Conferencing & Interactive Whiteboard System Development

## Objective
Develop a comprehensive internal video conferencing platform with interactive whiteboard capabilities for the TutEasy tutoring CRM platform. This system will replace external Zoom integration and provide MyTutor-level features with full control over user experience and costs.

## Key Requirements
1. WebRTC implementation for peer-to-peer video communication
2. Real-time collaborative whiteboard with <50ms latency
3. Session recording with reliable playback
4. Screen sharing capabilities
5. Mathematical notation support
6. Text chat and file sharing during sessions
7. FERPA/COPPA/GDPR compliance
8. Integration with existing booking and user management systems

## Technical Constraints
- Node.js/Express backend with PostgreSQL/Prisma ORM
- React/TypeScript frontend
- Existing authentication and authorization system
- Current booking and payment integration points

## Success Metrics
- Video quality matching/exceeding MyTutor standards
- Whiteboard collaboration with <50ms latency
- 99.9% session establishment success rate
- User satisfaction score >8/10
